# Spec Delta

## ADDED Requirements

### Requirement: A type may be authored by an agent

The type registry SHALL allow a type to declare `author: agent`. When such a type
is requested, the system MUST send the request's `CONTENT` to the agent authoring
endpoint and MUST return the rendered artifact as that asset's content and format.
It MUST NOT author a content spec or generate markup for such a type: the asset is
the file the agent rendered, not a composition the workflow built.

#### Scenario: Agent-authored asset produced
- **WHEN** a request includes a type that declares `author: agent`
- **THEN** the request's `CONTENT` is sent to the agent authoring endpoint
- **AND** the asset carries the rendered file's content and its declared format

#### Scenario: Content, not a reference
- **WHEN** an agent-authored asset is returned
- **THEN** it carries the artifact's content and format
- **AND** not a path, URL or filename

#### Scenario: Agent failure is isolated
- **WHEN** the agent authoring endpoint fails or returns no artifact
- **THEN** that asset carries the error
- **AND** every other asset of the request is unaffected

### Requirement: The agent's markup does not enter the workflow

For a type that declares `author: agent`, the markup is authored by the agent
inside its sandboxed runtime and rendered there. The workflow MUST NOT author,
receive as asset content, or execute that markup; it MUST carry only the rendered
artifact and its declared format.

#### Scenario: Only the rendered artifact crosses the boundary
- **WHEN** an agent-authored type is produced
- **THEN** the workflow obtains a rendered artifact
- **AND** neither authors nor receives the agent's composition markup

## MODIFIED Requirements

### Requirement: Authoring is two-stage

For every infographic-family type the system SHALL first produce a typed **content spec** as data, and MUST derive the rendered markup deterministically from that spec. The model MUST NOT author the markup. The spec SHALL carry the title, the ordered labelled blocks with their values, the accent, the motion kind and the duration; a spec missing required fields MUST fail loudly rather than render a partial asset. This requirement applies to the deterministic family (`raster`, `spec_raster`, `spec_markup`, `spec_service`); a type declaring `author: agent` is authored by the agent path instead.

#### Scenario: Spec then markup
- **WHEN** an infographic-family asset is produced
- **THEN** a content spec exists first
- **AND** the rendered markup is generated by deterministic code from that spec

#### Scenario: Invalid spec
- **WHEN** the produced spec is missing a required field
- **THEN** the run fails naming the missing field
- **AND** no markup or image is produced for it
